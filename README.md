# Ассистент по БЦ — SUMMIT Business Center

CRM для управления арендой в бизнес-центре: сделки, помещения, арендаторы,
воронка (горячие/тёплые/холодные/выиграно/проиграно).

## Что это технически

- **Одностраничное статическое приложение** — весь код (HTML + CSS + JS) в одном
  файле `leasing-crm-v2.html`. Сборка и зависимости не требуются.
- **Данные хранятся локально в браузере** (`localStorage`), backend отсутствует.
  Есть встроенная миграция схемы данных (`migrateDB`).
- **Внешние обращения** — только к Google Fonts (шрифты Space Grotesk / Inter).
  Никаких API, токенов или серверных вызовов.

## Как запустить

Проект отдаётся как статика любым HTTP-сервером. Штатный способ (см.
`.claude/launch.json`):

```bash
python -m http.server 8123
```

Затем открыть <http://localhost:8123/> (редирект на приложение) или напрямую
<http://localhost:8123/leasing-crm-v2.html>.

## Структура

| Файл                     | Назначение                                   |
| ------------------------ | -------------------------------------------- |
| `leasing-crm-v2.html`    | Само приложение (единственный артефакт)      |
| `index.html`             | Редирект на приложение при заходе на `/`     |
| `.claude/launch.json`    | Конфиг запуска (`http.server` на порту 8123) |

> `.claude/settings.local.json` — локальные настройки машины разработчика,
> в репозиторий не коммитятся (см. `.gitignore`).
